# Zepto E-Commerce SQL Project
An SQL data analysis project on Zepto dataset focusing on product pricing, discounts, stock status, and category insights.

## 📌 Overview
This project focuses on analyzing the Zepto grocery delivery dataset using SQL. The objective is to extract meaningful insights related to product pricing, discounts, availability, and category-wise performance to support data-driven decision making.

## 📊 Dataset Description
The dataset contains information about products available on Zepto, including:
- Product name
- Category
- Price and discounted price
- Availability status
- Quantity and unit details

## 🚀 Key Analysis Performed
- Category-wise product distribution
- Price vs discounted price comparison
- Identification of high-discount products
- Availability analysis of products
- Data cleaning and filtering using SQL queries

## 🛠️ Tech Stack
- SQL
- PostgreSQL / MySQL
- CSV Dataset

## 📂 Project Structure
- `zepto_v2.csv` – Original dataset  
- `Zepto_E-Commerce.sql` – SQL queries used for analysis  

## ⚙️ How to Run
1. Create a database in PostgreSQL/MySQL  
2. Import the `zepto_v2.csv` file into a table  
3. Execute SQL queries from `Zepto_E-Commerce.sql`  
4. Analyze the results using SELECT queries  

## 📈 Insights & Findings
- Certain categories offer higher discounts compared to others
- Price variations exist for similar products across categories
- Availability plays a key role in product visibility
